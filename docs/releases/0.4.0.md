# Minecraft Server Hub 0.4.0

## 主な変更

- ホーム、サーバー、プレイヤー、テンプレート、発見、ニュースをまとめた新しいワークスペースナビゲーションを追加しました。
- サーバー、テンプレート、プレイヤー管理、設定を横断するグローバル検索を追加しました。
- MinecraftとPalworldの両方で、安全なサーバーファイル管理に対応しました。
- Palworldにファイル、バックアップ、アクセスログを追加し、ゲーム固有機能を6つのタブへ整理しました。
- 起動、停止、再起動、クラッシュ、エラー、不明状態の表示と状態遷移を改善しました。
- 幅の狭いウィンドウでもサーバー選択と主要ページ移動ができるモバイルナビゲーションを追加しました。
- 新しい画面と操作を9言語へ反映しました。

## 安全性

- ファイル操作を登録済みサーバーフォルダー内に制限しました。
- 親フォルダーへの移動、絶対パス、シンボリックリンク経由のアクセスを拒否します。
- サーバー稼働中のファイル変更を拒否し、変更操作を監査ログへ記録します。
- 対応テキストファイルの保存には原子的な置換を使用します。

## 更新について

この更新は、アプリ内の「アプリの更新」から確認し、ユーザーが許可した場合にのみ適用されます。更新パッケージはアプリ内蔵の公開鍵で検証され、検証に失敗した場合は現在のアプリを維持します。
