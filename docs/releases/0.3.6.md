# Minecraft Server Hub 0.3.6

Palworldサーバーの削除方法を、待ち時間と復旧要件に合わせて選べるようにしました。

- 「重要データを保存して高速削除（おすすめ）」を追加しました。ワールド、設定、Modを署名付きアプリのバックアップ保存先へ残し、SteamCMDで再取得できる公式サーバーファイルをバックアップ対象から外します。
- 「バックアップせず今すぐ削除」を追加しました。最終バックアップを作成せず、登録済みのPalworldサーバーフォルダーを削除します。
- 高速バックアップには`Pal/Saved`、一般的なModフォルダー、コミュニティPak、Steam WorkshopのPalworldコンテンツを含めます。ログ、クラッシュ記録、プロファイル情報、`Pal-WindowsServer.*`公式ファイルは含めません。
- 削除処理は引き続きUIスレッド外で実行するため、処理中もアプリ画面が応答できます。
- どちらの削除方法も、停止中のサーバー、登録済みPalworld構成、半角`Delete`の一致を確認してから実行します。
- 9言語すべてに、選択肢、復旧方法、バックアップなし削除の取り消せない警告を追加しました。
- Minecraftサーバーでは従来どおり「一覧から外す」または「最終バックアップ後にフォルダーも削除」を使用します。

## 安全性

「重要データを保存して高速削除」のバックアップには、参加パスワードや管理者パスワードが含まれる場合があります。第三者へ共有しないでください。

「バックアップせず今すぐ削除」は復旧できません。残したいワールド、設定、Modがある場合は高速削除を選んでください。

実在するユーザーのサーバーは自動テストで削除せず、隔離した一時サーバーフォルダーだけでバックアップ、整合性確認、削除を検証します。

## 検証対象

- 重要データだけを含むZIPの作成とSHA-256整合性確認
- 公式Palworld PAKおよびログが高速バックアップへ入らないこと
- バックアップなし削除でZIPやメタデータを作成しないこと
- UIから`essential`／`none`が正しくバックエンドへ渡ること
- 9言語の削除文言がすべて欠けず、モードごとに区別できること
- Minecraftの既存削除、全フロントエンド、Rust、Developer Tools、UI操作の回帰
