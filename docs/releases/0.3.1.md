# Minecraft Server Hub 0.3.1

## 変更内容

- Palworldサーバー取得の開始直後から、進捗欄を`0.0%`で表示するようにしました。
- 新しいSteamCMDがコンソールへ出す実測パーセントと取得容量を読み取れるようにしました。
- 実測値を0.5秒ごとに反映し、長時間止まってから急に進んで見える状態を改善しました。
- SteamCMDが総容量を確定した後は、取得済み容量／総容量と通信速度を併記します。
- 作成ボタンを押す前から進捗イベントを受信し、最初の通知を取りこぼさないようにしました。
- GitHub Releases上の署名済み更新フィードを標準設定し、次回以降は設定画面から新しいバージョンを確認できるようにしました。

## 更新時の安全性

- 既存のMinecraft／Palworldサーバー、ワールド、設定は置き換えません。
- アプリ更新は署名検証に成功した場合だけ適用します。
- 検証に失敗した場合は、現在インストールされているアプリを維持します。
