# 0.3.4 Palworldサーバー削除 実機確認

- [ ] 0.3.4へ更新後も、既存のMinecraft・Palworldサーバー一覧が残っている。
- [ ] 停止中のPalworldサーバーでごみ箱ボタンを押すと、「一覧から外す」と「フォルダーも削除」が表示される。
- [ ] 「一覧から外す」では登録だけが消え、Palworldサーバーフォルダーとワールドが残る。
- [ ] 「フォルダーも削除」を選ぶと、バックアップ内のパスワードについて注意が表示される。
- [ ] `Delete` 以外では削除ボタンが有効にならない。
- [ ] 起動中・起動処理中・停止処理中のPalworldサーバーは削除できない。
- [ ] `Delete` と入力して確認した場合だけ、最終バックアップの作成・検証後に登録済みフォルダーが削除される。
- [ ] バックアップ保存先に削除直前のZIPとメタデータが残り、検証結果が正常になる。
- [ ] 別の一時フォルダーや親フォルダーが削除されていない。
- [ ] Minecraftサーバーの登録解除・フォルダー削除も従来どおり動作する。
- [ ] 削除完了後もアプリが開いたままになる。
