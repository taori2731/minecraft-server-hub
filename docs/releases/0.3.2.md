# Minecraft Server Hub 0.3.2

## 変更内容

- 更新フィードURLを空欄にしたとき、署名済みの公式更新フィードが有効であることを明確に表示します。
- 公式フィードの説明を日本語、英語、ドイツ語、スペイン語、フランス語、韓国語、ポルトガル語、中国語（簡体字／繁体字）の9言語へ反映しました。
- ブラウザデモの更新状態を、公式フィードが標準設定されたインストール版と一致させました。

## 更新時の安全性

- 既存のMinecraft／Palworldサーバー、ワールド、設定は置き換えません。
- アプリ更新は署名検証に成功した場合だけ適用します。
- 検証に失敗した場合は、現在インストールされているアプリを維持します。
