# Minecraft Server Hub 0.3.10

アプリ内更新用のWindows x64配布版です。新しいUI案を反映し、ホーム画面・サーバー一覧・サーバー詳細の導線を整理しました。

- ホーム画面に選択中サーバーの状態、操作、プレイヤー数、接続先、コンソールへの導線をまとめました。
- サーバー一覧に検索、実行中サーバーの表示、Minecraft/Palworldに応じたナビゲーションを追加しました。
- サーバー詳細をダークテーマ中心の運用コンソールへ整理し、既存の起動・停止・再起動・設定・自動運用を同じ画面から使えるようにしました。
- 既存のPalworld自動運用、バックアップ、通知の機能は継続して利用できます。
- ブラウザ遠隔管理・共同管理・中継サービス・共同管理用の権限／監査UIを削除しました。通常のゲーム接続用の友達招待（UPnP／playit）は継続します。
- 旧版に残る共同管理用のローカルテーブルと資格情報は、既存サーバーの登録を消さずに初回起動時の限定的な後処理で整理します。
- 日本語を含む9言語のホーム画面ラベルを追加しました。

## 配布と検証の範囲

0.3.9と同じTauri Updater署名方式でWindows x64向けNSISインストーラーを配布します。SignPathとWindows Authenticodeは通常のアプリ内更新の必須条件ではありません。アプリ内更新は、隣接`.sig`を埋め込み公開鍵で検証してからインストーラーを起動します。

Release資産は次の4つです。

- `Minecraft.Server.Hub_0.3.10_x64-setup.exe`
- `Minecraft.Server.Hub_0.3.10_x64-setup.exe.sig`
- `latest.json`
- `SHA256SUMS.txt`

GitHub Actionsは、版番号・公開鍵不変・回帰テスト・Tauri署名・SHA-256・マニフェストを確認し、公開前Artifactを保存してから`v0.3.10`をDraftで作成します。Draftから3つのUpdaterファイルを再取得して検証し、成功した場合だけLatestへ変更します。その後、公開Latestフィードと資産を再取得してローカル版と比較します。

実サーバーへの設定変更と、実際にインストール済み0.3.9へ自動更新を適用した受入は、このソース変更・CI構成の完了とは別の証跡です。
