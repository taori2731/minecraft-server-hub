# Minecraft Server Hub 0.3.10

アプリ内更新用のWindows x64配布版です。新しいUI案を反映し、ホーム画面・サーバー一覧・サーバー詳細の導線を整理しました。

- ホーム画面に選択中サーバーの状態、操作、プレイヤー数、接続先、コンソールへの導線をまとめました。
- サーバー一覧に検索、実行中サーバーの表示、Minecraft/Palworldに応じたナビゲーションを追加しました。
- サーバー詳細をダークテーマ中心の運用コンソールへ整理し、既存の起動・停止・再起動・設定・自動運用を同じ画面から使えるようにしました。
- 既存のPalworld自動運用、バックアップ、通知の機能は継続して利用できます。
- ブラウザ遠隔管理・共同管理・中継サービス・共同管理用の権限／監査UIを削除しました。通常のゲーム接続用の友達招待（UPnP／playit）は継続します。
- 旧版に残る共同管理用のローカルテーブルと資格情報は、既存サーバーの登録を消さずに初回起動時の限定的な後処理で整理します。
- 日本語を含む9言語のホーム画面ラベルを追加しました。

## 配布と検証の範囲

Windows x64向けNSISインストーラー、Tauri更新署名、更新マニフェストをGitHub Releasesへ配布します。アプリ内更新は署名を検証してからインストーラーを起動します。実サーバーへの設定変更と既存環境への自動更新適用は、この配布作業では確認していません。

フロントエンドの型チェック・ビルド・回帰テスト、Rustのビルド、更新署名の公開鍵検証、マニフェストと配布ファイル名の一致を確認しています。検証記録は同バージョンの`artifacts/updates/0.3.10`へ保存します。
