# TomoNode 0.4.4

0.4.4 は、料金プランを廃止し、任意の支援を検討する方針へ切り替えたリリース候補です。これはソース準備段階であり、公開版・インストーラー・決済サービスの提供を示すものではありません。

## 主な変更

- 「無料版とPro／サポーター版」の比較、価格表示、購入導線を通常UIから削除しました。
- 安定機能と安全機能は、支援の有無にかかわらず全員が無料で利用できます。
- 既存の「Pro運用」画面は「高度な運用」へ改称し、複数サーバー操作、監視、履歴、Mod構成、外観を全員が利用できる状態を維持しました。
- 「プラン」画面は「TomoNodeを応援」へ変更しました。支援は任意で、将来の新機能の先行体験、開発中機能へのフィードバック参加、限定外観を候補として案内します。
- 支援受付は準備中です。支援を停止した後も、安全機能、バックアップと復元、サーバーデータへのアクセスを制限しません。
- 応援方針とリリース案内を日本語、英語、ドイツ語、スペイン語、フランス語、韓国語、ポルトガル語（ブラジル）、中国語（簡体字・繁体字）へ反映しました。

## 互換性のため維持する値

- Tauri `productName`: `Minecraft Server Hub`
- Tauri `identifier`: `local.minecraft-server-hub.desktop`
- Windowsインストーラー資産名、Updater公開鍵、公式更新フィード
- アプリデータ、Credential Manager、DPAPI、SQLite、`.mshmove`の既存形式
- 既存サーバー、ワールド、設定、テーマ、バックアップ、更新処理

アプリ本体のroot版、Cargoパッケージ版、Cargo.lock内の`minecraft-server-hub`、Tauri設定、ブラウザデモ版は`0.4.4`へ揃えています。依存ライブラリのバージョンは変更していません。

- 寄付先、受付方法、価格、決済方法、ライセンス条件は未決定です。
