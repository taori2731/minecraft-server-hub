# Minecraft Server Hub 0.3.8

Palworldサーバーでも「自動運用」タブから無人時の安全停止とWindows通知を設定できるようにしました。

- 自動停止までの待機時間を5・10・15・30・60・120分から選択できます。
- ローカルREST APIで人数を確認し、無人時間が設定値に達するとワールドを保存して安全停止します。
- 人数の取得失敗時は無人時間をリセットします。人数情報に差がある場合は多い方を使います。
- 起動完了・プレイヤー参加・クラッシュのWindows通知を切り替えられます。
- Minecraft専用の移行・Mod検査・更新センター・バックアップ失敗通知はPalworldには表示しません。
- Palworld向けの説明を9言語へ追加しました。

自動運用中はアプリを起動しておく必要があります。自動停止・起動完了通知・参加通知にはローカルREST APIと管理者パスワードの設定が必要です。

## 配布と検証の範囲

Windows x64向けインストーラー、更新用署名、更新マニフェストを配布します。実サーバーの自動停止・Windows通知、および既存環境への更新適用は未確認です。

機能実装時にフロントエンドビルド、修正対象の回帰テスト、多言語UIスモーク、Rustテスト（153件成功・12件スキップ）を確認しています。配布物の検証記録は同バージョンのartifacts/updatesフォルダーへ保存します。
