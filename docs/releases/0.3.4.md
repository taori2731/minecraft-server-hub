# Minecraft Server Hub 0.3.4

Palworldサーバーでも、Minecraftサーバーと同じ削除範囲を選べるようになりました。

- 「一覧から外す」は、アプリの登録だけを解除し、サーバーフォルダーとワールドをPCに残します。
- 「フォルダーも削除」は、削除直前に最終バックアップを作成・検証してから、登録済みのPalworldサーバーフォルダーだけを削除します。
- フォルダー削除には、言語に関係なく確認欄へ半角で `Delete` と入力する必要があります。
- サーバーが起動中、起動処理中、停止処理中の場合は削除できません。
- `PalServer.exe`、公式サーバー実行ファイル、既定設定ファイルをすべて確認できないフォルダーは削除しません。
- Palworldの最終バックアップには参加パスワードと管理者パスワードが含まれる場合があるため、9言語で注意を表示します。

既存のMinecraft削除、最終バックアップ、停止処理、Palworldの招待、設定、監視機能は維持しています。

## セキュリティと復旧

削除対象は登録済みサーバールートを正規化し、ユーザーフォルダー、デスクトップ、ドキュメント、ダウンロード自体は削除対象にできません。最終バックアップのZIPとSHA-256メタデータはアプリのバックアップ保存先に残ります。

Palworldのバックアップにはサーバー設定上のパスワードが含まれる場合があります。バックアップを第三者へ共有しないでください。
