# Minecraft Server Hub 0.3.5

Palworldサーバーを「バックアップして削除」すると応答停止やファイル操作エラーになる問題を修正しました。

- 4 GiB以上の単一ファイルを含むサーバーでも、ZIP64形式で最終バックアップを作成します。
- バックアップ、整合性確認、フォルダー削除をUIスレッド外で実行し、処理中もアプリ画面が応答できるようにしました。
- バックアップに失敗した場合は、サーバーフォルダーとアプリの登録を削除しません。
- 削除対象のPalworld公式サーバー構成確認、保護フォルダー確認、半角`Delete`確認を維持しています。

## 安全性

Palworldの最終バックアップには参加パスワードや管理者パスワードが含まれる場合があります。バックアップを第三者へ共有しないでください。

実在するユーザーのサーバーは自動テストで削除せず、隔離した一時サーバーフォルダーでバックアップ、検証、削除を確認します。

- ZIP64境界テスト、Palworld最終バックアップ、整合性確認、隔離フォルダー削除テストに成功
