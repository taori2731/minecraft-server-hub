# Minecraft Server Hub 0.3.7

Minecraftサーバーでも、削除時に「バックアップせず今すぐ削除」を選べるようにしました。

- 「一覧から外す」「最終バックアップ後にフォルダーも削除」に加え、「バックアップせず今すぐ削除」を追加しました。
- バックアップなし削除では、登録済みのMinecraftサーバーフォルダーを直ちに削除します。ワールド、設定、Mod、プラグインも残りません。
- 停止中のサーバーかを確認し、全言語共通の半角`Delete`と最終確認がそろった場合だけ実行します。
- バックアップなし削除の選択肢、警告、最終確認、処理中表示を9言語へ追加しました。
- 従来の最終バックアップ付き削除と、Palworldの3種類の削除方法はそのまま利用できます。

## 安全性

「バックアップせず今すぐ削除」は取り消せません。残したいワールド、設定、Mod、プラグインがある場合は「フォルダーも削除」を選び、最終バックアップを作成してください。

実在するユーザーのサーバーは自動テストで削除せず、隔離した一時Minecraftサーバーフォルダーだけでバックアップなし削除を検証します。

## 検証対象

- Minecraftのバックアップなし削除でZIPやメタデータを作成しないこと
- 登録済みMinecraftサーバーフォルダーが削除されること
- UIから`backupMode: "none"`が正しくバックエンドへ渡ること
- 9言語のMinecraft専用警告がすべて欠けていないこと
- 従来のバックアップ付き削除、Palworld削除、全フロントエンド、Rust、Developer Tools、UI操作の回帰
