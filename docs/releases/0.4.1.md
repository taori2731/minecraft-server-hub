# Minecraft Server Hub 0.4.1

0.4.1は、ホーム画面の情報構成を見直した開発版です。

## UI

- 初期表示でサーバー概要、詳細タブ、主要メトリクスを確認できるよう配置を整理しました。
- ホーム画面の「遊び方を広げる」セクションを削除しました。
- 選択中サーバーの右側にあった「友達と遊ぶ」カードを削除しました。
- サーバー詳細のクイック操作は「アクセスログ」「バックアップ」「ファイル管理」に整理しました。
- タイトルバーの通常の「友達を招待」と、既存の友達招待機能は維持しています。

## アプリ内更新

- 通常のWindows更新は、0.3.9および0.4.0と同じTauri Updater署名方式を使用します。
- `src-tauri/updater-public.key`とTauri設定の公開鍵は変更していません。
- 隣接`.sig`、埋め込み公開鍵による検証、SHA-256、`latest.json`のHTTPS検証を公開ゲートにします。
- SignPathおよびWindows Authenticodeは、通常のアプリ内更新の必須条件に含めません。

## 互換性

Minecraft、Palworld、通常の友達招待、UPnP、playit、統合版招待のゲームサーバー機能は、このリリースノートのUI整理以外は変更していません。

このファイルはRelease公開時のノートです。署名、GitHub Release、公開後ダウンロード、インストール済み旧版からの更新は、それぞれの実行証跡で確認します。
