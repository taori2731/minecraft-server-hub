# TomoNode 0.4.3

## 主な変更

- 既存のスタートメニューとデスクトップのショートカット名を、更新時に`Minecraft Server Hub`から`TomoNode`へ移行します。
- ショートカットのリンク先がTomoNode本体と一致する場合だけ変更し、同名の別ショートカットは上書きしません。
- アンインストール時はTomoNodeが作成した新名称のショートカットも削除します。
- Windowsの既存インストール、サーバー、ワールド、設定、テーマ、バックアップ、更新署名との互換性を維持します。

## 互換性のため維持する値

- Tauri `productName`: `Minecraft Server Hub`
- Tauri `identifier`: `local.minecraft-server-hub.desktop`
- Windowsインストーラー資産名: `Minecraft.Server.Hub_*`
- Updater公開鍵と公式更新フィード
- アプリデータ、Credential Manager、DPAPI、SQLite、`.mshmove`の既存形式

これらはWindowsと既存データの互換性に関わる内部値です。アプリ画面、ウィンドウタイトル、通知、ショートカットの表示名は`TomoNode`です。

## 検証

- TypeScript型チェックと全体テスト
- ルートUI smokeとWebsite UI smoke
- Tauri NSISパッケージ生成
- Tauri Updater署名と埋め込み公開鍵の一致
- インストーラー、`latest.json`、隣接`.sig`、`SHA256SUMS.txt`の整合

Windows Authenticode署名は付与していません。Tauri Updater用の署名は検証済みです。
