# 0.3.3 実機確認

未確認の項目は完了扱いにしません。既存ワールドで確認する場合は先にバックアップしてください。

## インストール

- [ ] MinecraftとPalworldのサーバーを停止し、アプリを閉じる。
- [ ] 署名検証済みの0.3.3インストーラーを実行する。
- [ ] 起動後のアプリのバージョンが0.3.3になっている。
- [ ] 既存サーバー一覧が残っている。

## Palworld設定

- [ ] 停止中のPalworldの「設定」に新しい編集欄が表示される。
- [ ] サーバー名を変更し、ゲーム用UDPポートを空きポート選択で設定する。選んだ番号を控える。
- [ ] 参加パスワードを設定し、経験値倍率を2.0へ変更して保存する。パスワードはこの記録に書かない。
- [ ] 起動後、概要の接続先が設定したポートになっている。
- [ ] Palworldから `127.0.0.1:選んだゲーム用ポート` に接続し、参加パスワードを入力する。REST管理ポートは使用しない。
- [ ] 参加パスワードが異なる場合は拒否され、正しい場合は参加できる。
- [ ] ゲーム内で設定した倍率の反映を確認する。
- [ ] アプリに参加中プレイヤーが表示される。
- [ ] ワールド保存と安全停止が成功し、アプリは開いたままになる。
- [ ] 再起動後に再参加でき、保存内容と変更した設定が残っている。

## 公開と更新

- [ ] Palworldの「友達を招待」から「友達と遊べるようにする」を押す。
- [ ] UPnP対応ルーターでは、起動と準備確認の後に友達用の公開アドレスが表示される。
- [ ] 別の家またはモバイル回線のPalworldから、表示された公開アドレスとポートを入力して参加できる。
- [ ] UPnP非対応回線では公式playit.gg中継を開き、初回だけアカウント連携とPalworld UDPトンネルを作成する。
- [ ] 中継の公開先は、選択中サーバーのゲーム用UDPポートと一致するトンネルだけが表示される。
- [ ] 公開停止後はUPnP割り当てとアプリが開始した中継が停止し、アプリは開いたままになる。
- [ ] REST管理ポートとパスワードが友達用表示、ログ、保存データへ露出していない。
- [ ] 上記の結果を確認してから下書きリリースを公開する。
- [ ] 公開ファイルを再ダウンロードし、SHA-256と更新署名を再検証する。
- [ ] 旧版の更新確認に0.3.3が表示される。
- [ ] ユーザーの更新操作後、再起動したアプリが0.3.3になる。

Tauri更新署名はWindowsのAuthenticode署名とは別です。
