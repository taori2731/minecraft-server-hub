# Minecraft Server Hub 0.3.3

Palworldの設定画面から、サーバー名、説明、接続ポート、最大人数、参加パスワード、管理者パスワードを変更できるようになりました。

経験値・捕獲・採取倍率、昼夜の速度、孵化時間、デスペナルティ、襲撃、ファストトラベル、拠点上限なども変更できます。空きポートの選択に対応しました。

設定はサーバー停止中に保存し、次回起動時に反映します。変更前の設定ファイルをバックアップし、未管理の設定項目を維持します。新しい設定画面は9言語に対応しています。

Palworldの「友達を招待」から、サーバーの起動、RESTによる準備確認、ルーターのUPnPポート公開、友達用アドレスの表示までをまとめて実行できるようになりました。UPnPを利用できない回線では、公式playit.gg中継へ切り替えられます。playit.ggを初めて使う場合だけ、公式画面でアカウント連携とPalworld用UDPトンネルの作成が必要です。

公開するのはPalworldのゲーム用UDPポートだけです。ローカルREST管理ポート、管理パスワード、参加パスワードは公開しません。友達へ渡す外部アドレスと、このPCで使う `127.0.0.1` の接続先は別欄で表示します。

## 検証状況

- 機能実装時: TypeScript 290件合格、Rust 146件合格（実環境用12件は未実行）。Palworld自動招待を含むUIスモーク成功。
- 実ゲームからの接続、参加パスワードの適用、ゲーム内倍率の確認は未完了です。
- UPnPやplayit.ggで表示した公開先へ、別回線のPalworldから実際に参加する確認は未完了です。
- 公開前に、署名付き配布物の検証と実機確認を行います。

## パスワードとバックアップ

Palworldの設定ファイルとそのバックアップにはサーバー動作に必要なパスワードが含まれます。サーバーフォルダーやバックアップを第三者へ共有する際は内容を確認してください。
