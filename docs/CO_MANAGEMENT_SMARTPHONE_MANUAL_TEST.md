# 共同管理スマートフォン手動試験

この手順は、公開ステージングへ接続した一時合成ホストで、実スマートフォンの表示・通信・操作を確認するためのものです。実際のMinecraft、Palworld、ゲームパスワード、実ユーザーデータは使用しません。

## 試験前の条件

- スマートフォンをモバイルデータ通信、またはテスト用PCとは別のWi-Fiへ接続する。
- 招待リンクはテスト参加者以外へ転送しない。リンク自体が一時的な参加資格情報です。
- ブラウザはSafariまたはChromeなど、普段使うスマートフォンブラウザを1つ用意する。
- スマートフォンの横幅で横スクロールが発生しないことも確認する。

## Editor試験

1. 共有された`Editor`招待リンクをスマートフォンで開く。
2. 招待画面が表示され、言語選択が操作できることを確認する。可能なら日本語以外を1つ選び、見出し・ラベルが切り替わることを確認してから試験言語へ戻す。
3. 表示名に、実名ではない試験用の名前を入力する。
4. 招待秘密が自動入力されていることを確認し、「共同管理に参加」を押す。
5. 一時ホストが自動承認するまで待ち、サーバー概要が表示されることを確認する。
6. 設定画面で最大人数を`20`から`24`へ変更する。
7. 申請前の確認画面に、変更前`20`と変更後`24`が同時に表示されることを確認する。
8. 申請を確定し、`rev. 2`、最大人数`24`、監査ログの設定変更行が表示されることを確認する。
9. ページを再読み込みし、セッションと`24`が維持されることを確認する。

## Viewer試験（可能なら別タブ・シークレットウィンドウ）

1. 共有された`Viewer`招待リンクを別タブまたはシークレットウィンドウで開く。
2. 表示名を入力して参加する。
3. サーバー概要と設定値を閲覧できることを確認する。
4. 設定申請ボタンが無効であり、閲覧者には変更権限がない旨が表示されることを確認する。

## 失効試験

EditorとViewerの確認が終わったら、作業者へ「切断してよい」と伝えてください。ホストFixtureを停止すると、両セッションが失効画面へ遷移することを確認できます。

## 合格条件

- 実スマートフォンで画面が空白にならない。
- 主要文字列、入力欄、ボタンが画面幅からはみ出さない。
- Editorで変更前後の値が確認でき、設定値・revision・監査ログが更新される。
- Viewerから変更を申請できない。
- 言語選択後も招待・設定・エラー画面が崩れない。
- Fixture停止後にセッションが残り続けない。

## この試験で証明しないこと

- 実Minecraft Java・Bedrock・Palworldの設定反映、再起動後反映。
- 実ゲームパスワードや実ユーザーデータの安全性。
- Tauri署名インストーラー、Windows Credential Manager、DPAPIのパッケージ受入。
- 本番の可用性、別端末・別回線を含む全組み合わせ。
