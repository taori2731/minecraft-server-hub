# Tauri updater鍵のローテーション移行手順

## 0.3.10での扱い

0.3.10では鍵をローテーションしません。`src-tauri/updater-public.key`、`src-tauri/tauri.conf.json`の`plugins.updater.pubkey`、0.3.9を署名したTauri秘密鍵をそのまま使います。これにより、0.3.9をインストール済みの利用者が0.3.10の更新署名を検証できる互換性を維持します。

秘密鍵、鍵パスワード、公開用リポジトリのトークンはチャット、Issue、ログ、リポジトリへ貼り付けません。0.3.10の通常リリースにSignPath申請やWindows Authenticode`Valid`は必要ありません。

## 将来ローテーションする場合

公開鍵の変更は、通常のバージョン更新とは別の移行プロジェクトとして実施します。

1. 現行鍵が安全に使用でき、旧版から新鍵版へ移行できるかを調査します。
2. 旧公開鍵を埋め込んだすべての対応版について、ブートストラップ版または利用者向け手動更新手順を設計します。
3. 新しい鍵を安全な署名環境で生成し、秘密鍵をリポジトリや成果物へ保存しません。
4. 新公開鍵を埋め込んだ移行版を、旧鍵で検証できる経路がある場合だけ作成します。旧鍵が漏えいした場合は旧鍵で正規更新を作らず、手動インストールへ切り替えます。
5. 移行版の設定、サーバー登録、バックアップ、通常の友達招待、Minecraft、Palworldが維持されることを確認します。
6. 新公開鍵で署名検証、更新、アンインストール、再インストールを隔離環境で確認します。
7. 旧Releaseと旧フィードを削除・上書きせず、移行完了後だけ新公開鍵のフィードを公開します。
