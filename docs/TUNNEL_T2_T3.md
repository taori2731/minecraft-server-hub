# Phase T2 / T3 / T4 ポート開放なし招待

## 実装済み

- playit.gg公式Windowsエージェントの署名・SHA-256・バージョン確認
- 公式ローカルIPC v2からの認証状態、ライフサイクル、トンネル一覧、公開接続先の取得
- 選択中サーバーの `127.0.0.1:<Minecraftポート>` と完全一致するトンネルだけを表示
- 接続先のコピー、再確認、招待停止、ローカル診断
- このPCから公開エンドポイントへTCP接続できるかを確認する外部経路テスト
- サーバー停止・再起動・削除・アプリ終了時のアプリ所有エージェント停止
- エージェントログ内のURL、IP、公開接続先、トークン候補の伏せ字
- 公式エージェントの自動検出と、サーバー起動・待受確認・既存トンネル再利用をまとめた「かんたん公開」
- 未導入時に限り、配布元・版・容量・ライセンス・管理者権限・Windowsサービス・保存先を確認してから公式x64 MSIを自動取得
- 公式MSI v1.0.10の固定URL、6,070,272 bytes、SHA-256、Windows Authenticode発行者をRust側で検証してから実行
- インストール後は一時MSIを削除し、既に検証済みの公式エージェントがある場合はダウンロードを省略
- Minecraftのホスト名だけが表示される接続先に対する `_minecraft._tcp` SRV解決と到達確認
- 接続済み時の状態確認を30秒間隔に抑え、画面とエージェントへの定常負荷を軽減
- Palworld専用の「友達を招待」画面から、サーバー起動、認証済みローカルRESTの準備確認、UPnPによるゲーム用UDPポート公開を一括実行
- UPnPに失敗した場合は公式playit.gg中継へ切り替え、選択中PalworldサーバーのUDPポートと一致するトンネルだけを表示
- PalworldにはMinecraft Bedrock用RakNetプローブを流用せず、ホスト側の表示だけで外部ゲーム接続成功を断定しない

SQLiteにはプロバイダー、エージェント保存先、ローカルポート、最終状態、確認日時、利用条件確認日時だけを保存します。パスワード、二要素認証コード、生トークン、ログインURL、公開接続先、エージェントログは保存しません。

## 初心者向けの流れ

1. 「友達と遊べるようにする」を押す。
2. playit.ggが未導入なら、アプリが示す配布情報とインストール内容を確認して同意する。
3. アプリが公式MSIを取得・検証して起動する。WindowsのUAC確認は利用者が行う。
4. 初回だけ、公式playit.gg画面でアカウント連携とMinecraft Java用トンネルを承認する。
5. アプリがサーバーを起動し、公式エージェントを検証して開始し、選択中サーバーの既存トンネルを探す。
6. 接続先が取得できた後にだけ「接続済み」と接続先を表示する。
7. 友達は表示された接続先をMinecraft Java版へ入力する。
8. 終了時は「招待を停止」を押す。

playit.gg公式Windowsエージェントの導入まではアプリ内から進められます。ただし、v1.0.10の安定版CLI/IPCには、アプリから新しいトンネルを作成する公開コマンドがありません。そのため、初回のアカウント承認とトンネル作成、WindowsのUAC確認だけは利用者が公式画面で行います。パスワード、二要素認証コード、生トークンをアプリへ入力させる自動化は行いません。

## 検証状況

- 公式MSI版CLI v1.0.10の署名・固定SHA-256検証: 自動テストあり
- 既存トンネルの検出、開始、停止、公開接続先取得: 実装済み
- SRVレコードの解決: 実DNSで確認済み
- 別ネットワークのMinecraft Java版からの参加: 2026-08-26に利用者から接続成功の報告あり
- 複数の一般利用者環境、すべてのISP・ファイアウォール・回線品質: 未検証

アプリの「外部経路をテスト」はホストPC側からのTCP到達確認です。別ネットワークのMinecraftによる実参加の代わりにはならず、すべての環境で友達が参加できることを保証しません。

PalworldのUPnP公開では、認証済みのローカルREST APIで選択中サーバーの稼働を確認してから、ゲーム用UDPポートだけをルーターへ割り当てます。REST管理ポートは外部公開しません。Palworldの通信はMinecraft BedrockのRakNetとは異なるため、公開先の表示は別回線のPalworldからの実参加を保証しません。UPnP非対応、二重ルーター、CGNATなどの環境では公式playit.gg中継を使います。
