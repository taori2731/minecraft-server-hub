# デスクトップUI更新（2026-09-11）

## 変更内容

ユーザーが最後に指定した3枚を優先し、風景バナー、画像付きマイサーバー、右側の選択中サーバー詳細、緑の選択状態を実装した。ダーク／ライトは同じ画面構成を使用する。

- ホームのサーバーカードと既存のサーバー一覧は同じ選択状態を共有する。
- 選択中サーバーの起動・停止・再起動、接続アドレスコピー、招待、コンソール、設定を既存処理に接続した。
- 左ナビにホーム・プラグイン／Mod・プレイヤー・自動運用を配置。Palworldでは非対応の拡張機能入口を表示しない。
- サーバー一覧を名前・種類・バージョンで絞り込める。検索だけでは選択中サーバーを変更しない。
- 概要のメトリクス、最近のログ、初心者向け案内を再配置。コンソールではヘッダーを小さくし、入力欄の表示領域を確保した。
- 作成ウィザードと拡張機能カタログのカード、進行表示、余白を調整した。
- 新規ホーム文言は9言語。既存のテーマ・カスタムアクセント・サーバーアイコンを維持する。
- 小さい画面では選択中サーバーの操作をバナー直下へ移す。画面切替時には内容を先頭へ戻す。

## ビルド・テスト結果

- 型チェックと本体ビルド成功。500KB超のJSチャンク警告は残る。
- 全体テスト：59ファイル／300件成功。その後追加した検索・ホーム経由Palworld切替のテストも1件成功。
- 最終の関連テスト：3ファイル／51件成功（ファイル名フィルターに一致するDeveloperToolsApp試験を含む）。
- 初回の全体試験では、新たに増えた同名ボタンを単一要素として検索する既存App試験が失敗した。対象をヘッダー／サーバー一覧／タブに限定して修正した。並行実行でタイムアウトした試験はワーカー数2での全体試験で成功した。
- ブラウザ確認：サーバー検索、Palworldカード選択、Palworldの非対応タブ非表示、Minecraftへ戻る操作、コンソール遷移、作成ダイアログ、テーマ切替。
- 1536×960、1280×800、960×720の表示を確認。1280pxと960pxではワークスペースのscrollWidthとclientWidthが一致し、ページ全体の横はみ出しなし。サーバーカード列は必要な幅で内部横スクロールする。
- 960×720でサーバー操作ボタンの下端は約519px、1536×960のコンソール入力欄の下端は約932px。画面内に収まる。
- 最終ブラウザのエラーログなし。

## 注意点

- UI刷新ではユーザーのサーバーデータを変更していない。
- 参考画像の市場・人気テンプレート・プレイヤー行動履歴など、新規バックエンドが必要な機能を完成済みとして追加していない。
- Tauri配布パッケージの作成・インストール・アプリ内更新配信はこのUI作業では行っていない。バージョンは変更していない。
- ブラウザデモでの確認と、Windows配布アプリ／実Minecraft・Palworldサーバーでの受入確認は別。
